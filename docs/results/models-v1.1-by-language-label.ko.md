# 언어별·라벨별 models v1.1: 놓침과 과잉 가림

배포한 v1.1 모델이 크기마다 무엇을 놓치고 무엇을 지나치게 가리는지를 언어별, 라벨별로 정리했습니다. newmean-pii-dataset
공개 테스트(54개 언어)와 README 표의 외부 데이터 네 가지(OpenPII 30개 언어, Gretel finance 7개 언어, Nemotron-PII 영어,
KDPII 한국어)입니다. 비율마다 바로 옆에 개수를 붙여 표본이 작은 곳이 보이게 했습니다. 모델 크기, 차단 목록, 사람 검토를
정하기 전에 쓰시는 언어와 라벨을 확인하는 데 쓰시고, 쓰시는 글의 표본으로도 재 보세요. 같은 표를 정렬해 볼 수 있고 데모와
같은 언어로 나오는 페이지: https://pii.newmean.ai/results/

- **놓침 %**: 공백이 아닌 개인정보 글자 중 가려지지 않은 비율(어떤 라벨로든 가려졌으면 가린 것으로 셈). **과잉 가림 %**:
  개인정보가 아닌 글자 중 가려진 비율. 칸마다 놓침 / 과잉 가림입니다.
- **라벨별**: 놓침 %는 정답 라벨별입니다. 과잉 가림 %는 모델이 가릴 때 쓴 라벨로 나눴고(2단계 라벨은 PERSON과 URL에
  합침), 분모는 그 데이터의 개인정보가 아닌 글자 전체라서 라벨 행을 더하면 반올림 차이 안에서 데이터 전체의 과잉 가림이
  됩니다. 줄표(—)는 그 데이터에 그 라벨의 정답 구간이 없다는 뜻입니다. 예를 들어 OpenPII는 조직 이름을 표시하지 않아서,
  모델이 거기서 가린 조직 이름은 과잉 가림으로 셉니다. 모델에는 IP_ADDRESS 라벨이 없고(선택 사항인 패턴 계층에 있음),
  다른 라벨로 가린 IP 주소는 찾은 것으로 셉니다.
- **모델만**: 크기마다 기본 파일로, 패턴 계층과 SDK의 단어 단위 확장 없이 2026-11-01에 한 번 잰 숫자입니다. README 표와
  기술 보고서(6절)의 숫자이고, 아래 전체 행은 그 표와 칸마다 같습니다.
  [models-v1.1-public-test.ko.md](models-v1.1-public-test.ko.md)는 공개 테스트를 SDK 기본 설정으로 재서, 언어 칸이
  여기보다 놓침은 최대 1.2%p 낮거나 0.4%p 높고, 과잉 가림은 최대 0.7%p 높습니다.
- **개수**: 정답 구간은 그 데이터의 개인정보 구간을 우리 라벨로 옮긴 것입니다(Nemotron-PII와 Gretel finance에서 우리
  기준 밖의 유형은 개인정보로도 과잉 가림으로도 세지 않음). †는 정답 구간이 100개 미만이라 구간 몇 개로도 비율이 1%p 넘게
  움직이는 곳입니다. 언어마다 정답 구간이 공개 테스트에서 287~343개(305~320행), OpenPII에서 672~832개(200행), Gretel
  finance에서 1,259~1,659개(394~400행)라서, 언어 사이 1%p 안팎의 차이는 몇 행으로도 바뀔 수 있는 범위입니다.
- 공개 테스트는 우리 학습 데이터와 같은 설계로 만들어서, 모델이 처음 보는 글보다 비율이 낮게 나옵니다. 외부 데이터가 더
  공정한 비교입니다. Gretel finance는 README 표의 모든 탐지기에 어렵습니다.

표는 `training/scripts/results_by_language.py`가 평가 보고서에서 만듭니다.
