# 공개 테스트에서 models v1.1: 라벨별, 형식별, 언어별

newmean-pii-dataset 공개 테스트(54개 언어 17,058행)에서 모델 크기마다 얼마나 놓치는지를, SDK 기본 설정(SDK 1.3~1.7: 단어
단위 켬, 패턴 계층 끔, 이모지는 모델이 읽는 글에서 뺌)으로 잰 숫자입니다. 어떤 라벨은 로컬 가리기로 충분하고 어디에 더 큰
모델, 차단 목록, 사람 검토를 둘지 정할 때 쓰세요. 우리 모델은 같은 설계의 데이터로 학습했기 때문에, 처음 보는 글보다 이 숫자가
낮게 나옵니다(README의 외부 데이터가 더 공정한 비교입니다). 쓰시는 글의 표본으로도 재 보세요.

- **놓침 %**: 공백이 아닌 개인정보 글자 중 가려지지 않은 비율(어떤 라벨로든 가려졌으면 가린 것으로 셈). **과잉 가림 %**:
  개인정보가 아닌 글자 중 가려진 비율. 숫자가 둘인 칸은 놓침 / 과잉 가림입니다.
- large·medium·small은 2026-11-03(1.3 배포 측정), nano는 2026-11-24에 쟀습니다. SDK 1.4~1.7은 기본 설정에서 같은 구간을
  내며, 2026-11-24에 다시 잰 medium이 1.3 측정과 모든 칸에서 같았습니다. 한 번씩 잰 숫자입니다.
- 언어마다 305~320행, 형식마다 529~1,767행입니다. 언어나 형식 사이 1%p 안팎의 차이는 몇 행으로도 바뀔 수 있는 범위입니다.
- 모델만 잰 숫자를 개수, 라벨별 과잉 가림, 외부 데이터 네 가지의 언어별·라벨별 표와 함께:
  [models-v1.1-by-language-label.ko.md](models-v1.1-by-language-label.ko.md).
