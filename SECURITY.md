# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately by e-mail to **hoonjae@newmean.ai**, not in a public issue or pull request.
Include the affected component and version, the steps to reproduce, and the impact you expect. We will acknowledge the
report and keep you informed while we work on a fix.

## Scope

- the JavaScript SDK (`@newmean-ai/pii`, `js/`)
- the site at pii.newmean.ai (`site/`)
- the leaderboard code (`leaderboard/`)

There is no bug bounty program.
