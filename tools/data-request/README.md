# Training data requests

The training and validation data of `@newmean-ai/pii` are not published; they are shared on request through
[this form](https://docs.google.com/forms/d/e/1FAIpQLScSMp2UvhNIlzc0EkDc2i6TwqKSzFc4bLR45DCnZSESlJzHzA/viewform). Research use
is free: non-commercial use only, no redistribution, and publications that use the data cite the
[technical report](../../docs/report/REPORT.md). Commercial use is licensed by inquiry (hoonjae@newmean.ai). The full terms come
with the approval email (research) or the contract (commercial). Requests are open now; the data is shared from December 2026, and approved applicants are emailed when access opens. The code behind the form is not published.
