# Training data requests

The training and validation data of `@newmean-ai/pii` are not published; they are shared on request through
[this form](https://docs.google.com/forms/d/e/1FAIpQLScSMp2UvhNIlzc0EkDc2i6TwqKSzFc4bLR45DCnZSESlJzHzA/viewform). Research use
is free: non-commercial PII research only, no redistribution, and publications that use the data cite the
[technical report](../../docs/report/REPORT.md). Commercial use is licensed by inquiry (hoonjae@newmean.ai). Requests are open
now; the data is shared from December 2026, and approved applicants are emailed when access opens. The code behind the form is
not published.

The license links point to the git tag `data-license-v0.3`, so they always show the text you accepted. A new license version is
published as a new file; version 0.3 is never edited. To check a copy, run `shasum -a 256 -c LICENSE-RESEARCH-v0.3.md.sha256`
in the folder that holds both files. For a licensee resident or established in Korea, the Korean text controls.
