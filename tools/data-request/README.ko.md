# 학습 데이터 요청

`@newmean-ai/pii`의 학습·검증 데이터는 공개하지 않고,
[요청 양식](https://docs.google.com/forms/d/e/1FAIpQLScSMp2UvhNIlzc0EkDc2i6TwqKSzFc4bLR45DCnZSESlJzHzA/viewform)으로 요청을 받아
공유합니다. 연구 목적 사용은 무료입니다. 비상업 PII 연구에만 쓸 수 있고 재배포는 금지하며, 데이터를 쓴 출판물에는
[기술 보고서](../../docs/report/REPORT.ko.md)를 인용해야 합니다. 상업적 사용은 문의로 라이선스합니다(hoonjae@newmean.ai).
신청은 지금 받고, 데이터는 2026년 12월부터 공유합니다. 승인된 신청자에게는 공유가 시작될 때 메일로 알려 드립니다. 양식을
처리하는 코드는 공개하지 않습니다.

이용계약 링크는 git 태그 `data-license-v0.3`을 가리키므로 늘 동의한 그 본문을 보여 줍니다. 새 버전은 새 파일로 게시하고, 0.3
본문은 고치지 않습니다. 사본을 확인하려면 두 파일이 있는 폴더에서 `shasum -a 256 -c LICENSE-RESEARCH-v0.3.ko.md.sha256`을
실행하세요. 대한민국에 거주하는 개인이나 대한민국에서 설립된 법인 라이선시에게는 한국어 본이 우선합니다.
